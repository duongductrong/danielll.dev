A beautiful gradient card that lifts up on hover, perfect for showcasing content or features.

<Preview component="gradientCard" />

## Features

- **Gradient Background**: Subtle purple to blue gradient
- **Hover Animation**: Card lifts up with shadow effect
- **Modern Design**: Clean and minimal aesthetic
- **Responsive**: Works well on all screen sizes

## Design Details

The card uses CSS gradients and Framer Motion for smooth animations:

- Background gradient: `from-purple-50 to-blue-50`
- Border color: `border-purple-200`
- Text gradient: `from-purple-600 to-blue-600`
- Hover effect: `whileHover={{ y: -5 }}`

## Use Cases

Perfect for:
- Feature highlights
- Product showcases
- Team member cards
- Service offerings
- Portfolio items

The subtle gradient and smooth animations create a premium feel that works great in modern web applications.
