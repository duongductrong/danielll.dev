## About the Zinc Theme

The zinc theme is one of the most popular color schemes in shadcn/ui, offering:

- **Neutral Elegance**: Sophisticated gray tones that don't compete with your content
- **Perfect Contrast**: Excellent readability in both light and dark modes
- **Professional Appeal**: Clean, modern aesthetic suitable for any application
- **Accessibility**: High contrast ratios meeting WCAG guidelines

## Color Palette

The zinc theme uses a carefully crafted scale from `zinc-50` (lightest) to `zinc-950` (darkest):

- **Light Mode**: Uses lighter zinc shades with dark text
- **Dark Mode**: Inverts to darker zinc shades with light text
- **Semantic Colors**: Maps to shadcn/ui's semantic color system

## Implementation

To use the zinc theme in your project:

1. **Install shadcn/ui**: `npx shadcn-ui@latest init`
2. **Select zinc theme**: Choose "Zinc" when prompted for base color
3. **Components**: Add components with `npx shadcn-ui@latest add [component]`
