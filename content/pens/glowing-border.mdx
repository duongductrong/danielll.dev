To implement the glowing border effect, I used the `conic-gradient` CSS property.

```css
background: conic-gradient(
  from 10deg,
  transparent 20%,
  #4eaffe 50%,
  transparent 20%
);
```

The `from 10deg` is the starting angle of the gradient. The `transparent 20%` is the color of the transparent part of the gradient. The `#4EAFFE 50%` is the color of the part of the gradient that is not transparent. The `transparent 20%` is the color of the transparent part of the gradient.

And the `width: 200%` and `height: 200%` class is used to make the gradient larger than the container.

export function GlowingBorderPart1() {
  return (
    <div
      className={join(
        [
          "overflow-hidden relative p-0.5 inline-block",
          "before:absolute rounded-xl",
          "before:top-[-50%] before:left-[-50%] before:right-0 before:bottom-0",
          "before:m-[-1px]",
          "before:w-full before:h-full before:bg-red-500",
          "before:[background:conic-gradient(from_10deg,transparent_20%,#4EAFFE_50%,transparent_20%)]",
          "before:w-[200%] before:h-[200%]",
          "before:origin-center before:duration-1000",
        ],
        " "
      )}
    >
      <div className="border-2 border-zinc-200 dark:border-zinc-700 bg-[#F5F5F5] dark:bg-[#171717] p-4 rounded-xl grid place-items-center size-16">
        <DatabaseZap className="size-6 text-zinc-500" />
      </div>
    </div>
  );
}

Then we need to add the spinning animation to the gradient. And for this, we need to use the `animate-spin` class. (animation from [Tailwind CSS Animations](https://tailwindcss.com/docs/animations)) on the `before` pseudo-element.

```css
before: animate-spin;
```

or you can use the `@keyframes` rule to animate the gradient.

```css
@keyframes spin {
  from {
    transform: rotate(0deg);
  }
  to {
    transform: rotate(360deg);
  }
}
```
