An interactive form that demonstrates state management and smooth transitions between form states.

<Preview component="interactiveForm" />

## Features

- **State Management**: Uses React useState for form state
- **Form Validation**: Built-in email validation
- **Success Animation**: Smooth transition to success state
- **Auto Reset**: Form resets after showing success message
- **Responsive Design**: Works on all screen sizes

## Implementation Highlights

### State Management
```tsx
const [email, setEmail] = useState("");
const [isSubmitted, setIsSubmitted] = useState(false);
```

### Form Handling
- Prevents default form submission
- Shows success state for 2 seconds
- Automatically resets form

### Animations
- **Form Exit**: Smooth fade out when submitted
- **Success Entry**: Scale and fade in animation
- **Auto Reset**: Automatic return to form state

## User Experience

1. User enters email address
2. Form validates email format
3. Success animation plays on submit
4. Form automatically resets after 2 seconds

This pattern is perfect for newsletter signups, contact forms, and any interaction where you want to provide clear feedback to users.

## Customization Options

- Change success message and icon
- Adjust animation timing
- Modify auto-reset duration
- Add additional form fields
- Customize styling and colors

The component demonstrates best practices for form UX and provides a delightful user interaction!
