This animated button showcases smooth hover animations and a continuously rotating icon. Perfect for call-to-action buttons that need to grab attention.

<Preview component="animatedButton" />

## Features

- **Hover Scale Effect**: Button scales up on hover for better interactivity
- **Tap Animation**: Provides visual feedback when clicked
- **Rotating Icon**: Sparkles icon rotates continuously
- **Gradient Background**: Beautiful purple to blue gradient
- **Smooth Transitions**: All animations are smooth and performant

## Usage

This component uses Framer Motion for animations and can be easily customized by adjusting the animation properties or changing the gradient colors.

## Key Animation Properties

- `whileHover={{ scale: 1.05 }}` - Scales the button on hover
- `whileTap={{ scale: 0.95 }}` - Provides click feedback
- `animate={{ rotate: 360 }}` - Continuously rotates the icon
- `transition={{ duration: 2, repeat: Infinity }}` - Controls the rotation timing

Perfect for buttons that need to stand out and provide engaging user interactions!
